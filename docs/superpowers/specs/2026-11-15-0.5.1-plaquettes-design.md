# 0.5.2 — Plaquettes de formation : conception courte

Validée par l'utilisateur le 2026-11-15.

**Intention.** Déposer les plaquettes PDF des formations dans le TMS et les envoyer : jointes à un devis, ou seules à un contact. Une plaquette peut concerner une formation, plusieurs formations ou tout un DAS (les deux cas existent chez CAP FORMATION).

**Approches.** 1) Bibliothèque de plaquettes rattachées à des formations et/ou des DAS — **retenue** : couvre les plaquettes par formation, communes et par DAS sans doublon de fichier. 2) Un fichier sur la formation + un sur le DAS — écartée : une brochure commune à plusieurs formations devrait être déposée et remplacée plusieurs fois.

**Décidé.**
- Catalogue → Plaquettes : titre, PDF (≤ 10 Mo, vérifié par contenu, stockage privé `TenantStorage`), formations et/ou DAS rattachés. Remplacer le fichier crée une nouvelle version ; les versions envoyées restent téléchargeables depuis l'historique de l'envoi.
- Droits : consulter = `catalogue.view`, déposer/modifier = `catalogue.manage`, supprimer = `catalogue.delete`. Une plaquette déjà envoyée se met à la corbeille (suppression logique), jamais d'effacement du fichier envoyé.
- Page formation : ses plaquettes (directes + celles de son DAS).
- Envoi d'un devis : case « Joindre les plaquettes » cochée par défaut ; plaquettes des formations des lignes, sans doublon, liste modifiable avant l'envoi ; les versions jointes sont enregistrées avec le devis (renvoi et relance rejoignent les mêmes versions).
- « Envoyer une plaquette » (fiche entreprise, fiche personne, opportunité) : plaquettes, destinataire (personnes de la fiche avec e-mail), message ; modèle d'e-mail `brochure` dans Administration → Modèles d'e-mails ; envoi en file (`TenantAwareJob`, `TenantMailer`) ; trace dans l'historique de la fiche (date, auteur, plaquettes, statut d'envoi).
- Limite totale des pièces jointes d'un e-mail : 20 Mo ; au-delà, message français et envoi refusé.

**Hors périmètre.** Statistiques d'ouverture, envoi en masse, plaquettes générées automatiquement depuis le catalogue (lot 2c).

**Laissé au constructeur.** Noms des tables et classes, forme exacte des écrans.
