# 0.7 — Formation type et assistant IA : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** une fiche formation complète (Qualiopi ind. 1) avec modules, dupliquable, remplie au besoin par une IA (programme PDF ou demande écrite) qui propose et que l'utilisateur valide.

**Architecture:** enrichissement du module **Catalogue** (colonnes de `trainings`, table `training_modules`, duplication, service public `Trainings` étendu pour les modules) ; connecteur **`ai`** dans `app/Modules/Connectors/Ai/` (interface `AiClient::structured(string $system, string $user, array $jsonSchema): array`, implémentations Anthropic et compatible OpenAI) ; assistant `Catalogue/Assistant/` (extraction de texte PDF, prompt, validation de la proposition) appelé par le Catalogue via le service public du connecteur (`Connectors\Ai\Ai`), jamais un fournisseur nommé dans le métier.

**Spec:** `docs/superpowers/specs/2026-11-16-0.7-formation-type-ia-design.md`.

Branche `lot-0.7-formation-type` depuis `main` (v0.6.0). VERSION → `0.7.0`.

## Global Constraints

- Règles du `CLAUDE.md` (RLS + `BelongsToTenant` + `Rls::enable`, référentiels par id + `ReferenceUsage`, français, TDD, secrets chiffrés, `HostPolicy` pour tout appel sortant, journaux sans contenu ni donnée personnelle, `UserFacingHttpException` pour un message affiché, module boundaries : Crm/Sessions n'importent du Catalogue que ses services publics).
- **Rien n'est enregistré par l'IA** : la proposition remplit le formulaire, l'utilisateur enregistre.
- Une valeur déjà saisie n'est remplacée que si l'utilisateur coche « garder la proposition » pour ce champ (décoché par défaut quand le champ est rempli).
- Sortie IA validée côté serveur contre le schéma (types, longueurs, nombre de modules ≤ 30, objectifs ≤ 20, durée 0 < h ≤ 2000) ; valeurs de référentiel (modalité) ramenées à un id existant de l'organisme ou laissées vides.
- PDF ≤ 10 Mo, type vérifié par le contenu ; texte envoyé tronqué à 60 000 caractères (constante documentée) ; aucun fichier conservé après l'analyse.
- Connecteur IA : un seul actif par organisme ; secrets chiffrés ; IA locale (adresse privée) seulement si « Serveur sur le réseau local » est coché, et seulement vers l'hôte:port enregistrés ; délai 120 s ; 20 demandes / heure / utilisateur ; journal `connector_runs` sans contenu.
- Messages d'erreur IA : fixes, en français, jamais le texte du fournisseur.

## Review Focus

1. **IA indisponible ou réponse invalide** (JSON cassé, champ trop long, modalité inconnue) → message français clair, rien n'est rempli de travers → tâche 3.
2. **Fiche déjà remplie + proposition IA** → aucun champ écrasé sans case cochée → tâche 4.
3. **IA locale sur 192.168.x.x** sans la case cochée → refus ; avec la case → seul cet hôte:port est joignable, pas un autre hôte interne (redirection refusée) → tâche 3.
4. **Duplication d'une formation utilisée par des sessions/dossiers** → la copie est indépendante (modifier la copie ne touche pas l'original), inactive, sans plaquettes → tâche 2.
5. **Somme des modules ≠ durée de la formation** → avertissement visible, enregistrement possible → tâche 1.
