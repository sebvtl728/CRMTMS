# 0.10 Documents — livraison 1 (moteur, convention, contrat) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Émettre, archiver et envoyer depuis un dossier la convention de formation (contractant entreprise) et le contrat de formation (particulier), avec des textes modifiables par l'organisme et la signature/cachet de la société.

**Architecture:** Nouveau module `app/Modules/Documents` qui lit Sessions par un nouveau service public `Sessions\Public\Paperwork`, le CRM par `Crm\Public\Fiches`, le catalogue par `Trainings`. Un document émis est figé (PDF archivé + sha256, déclencheur d'inaltérabilité), comme une facture ; l'envoi reprend la mécanique `InvoiceSender` / `SendInvoice`. Textes : catalogue de blocs dans le code + surcharges en base par organisme / société.

**Tech Stack:** Laravel 12, PostgreSQL 17 (RLS), Gotenberg (`Core\Documents\PdfRenderer`), Inertia React 19 TS, Pest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-19-0.10-documents-signature-design.md` (fait autorité).

## Global Constraints

- Branche `lot-0.10-documents` (partie de `qualiopi`). Tests verts avant chaque commit ; commits en anglais, style conventionnel, trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Toute table métier : `tenant_id uuid not null`, `BelongsToTenant`, `Rls::enable` ; migrations via `--database=pgsql_owner`.
- Interface et messages en français ; dates `d/m/Y` de Paris.
- Erreur affichée = `UserFacingHttpException` ou erreur de validation.
- Fichiers : `TenantStorage::path('documents', …)` (zone à ajouter à `TenantStorage::AREAS`), disque `TenantStorage::DISK`.
- PDF : `PdfRenderer::fromHtml`, gabarits Blade sans ressource externe, CSP `default-src 'none'; img-src data:; style-src 'unsafe-inline'; font-src data:`, `{{ }}` seulement, images en data URI.
- Montants en centimes entiers (`brick/math`), jamais de flottant.
- Données personnelles (destinataire figé, adresses e-mail, message) dans `$auditPersonal`, jamais dans les logs.
- `Documents` n'importe de Sessions que `Sessions\Public\*`, du CRM que `Crm\Public\*`, du catalogue que `Trainings|TrainingData|TrainingUsage`, de Connectors que `Smtp\TenantMailer|SmtpHostRefused`, `Core\ConnectorRun|PermanentDeliveryFailure` ; aucun module n'importe `Documents`.
- Numéro : `DOC-<année de Paris>-<NNNNN>` (5 chiffres), continu par organisme et année, attribué en transaction (mécanique `QuoteNumbering`).
- Contrat de particulier : délai de rétractation **14 jours** à compter de la signature.

## Review Focus

- Dossier dont le contractant est mis à la corbeille ou anonymisé après l'émission : le document archivé reste servi tel quel ; une nouvelle émission est refusée avec un message français.
- Gotenberg en panne à l'émission : 503 « PdfRenderingFailed », aucun numéro consommé, aucun fichier laissé.
- Archive supprimée ou modifiée sur le disque : téléchargement 410, envoi refusé (empreinte).
- Utilisateur hors périmètre du dossier : 404 sur toutes les routes du document (pas 403).
- Texte personnalisé contenant un champ inconnu `{xyz}` ou HTML : refusé à l'enregistrement ; jamais interprété comme HTML dans le PDF.
